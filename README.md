## 主题特色

| 功能 | 说明 |
| --- | --- |
| 蕾塞花田视觉 | 暖金与墨绿配色、花田主视觉、萌版蕾塞伙伴，可设置首页标题、副标题和页脚短句。 |
| 明亮与夜里模式 | 支持固定明亮、固定夜里，或按北京时间自动切换；默认夜里模式。 |
| 可调玻璃面板 | 面板透明度、毛玻璃模糊和背景显影独立配置，并提供访客本地覆盖入口。 |
| 卡片与列表 | 首页卡片/列表视图；迷你高密度、紧凑、舒适、宽松四档卡片尺寸，默认紧凑。 |
| 实时监控与历史图表 | 支持 HTTP 轮询或 WebSocket 连接，包含资源负载、网络和 Ping 图表相关模块。 |
| 服务器对比 | 包含服务器对比、健康摘要、拓扑和厂商信息等面板，实际数据取决于后端提供的字段。 |
| 快捷筛选 | 可配置收藏、高负载、离线和即将到期等快捷控制，以及离线服务器置底。 |
| 首页与详情定制 | 自定义总览指标、详情卡片和图表；GPU、磁盘预测等功能由配置开关控制。 |
| 地区连线 | 按服务器地区展示汇向中国的连接示意，可关闭；不是实际路由追踪或流量目的地统计。 |
| 自定义背景 | 明亮/夜里分别设置图片或视频地址，支持背景模糊和遮罩；默认使用内置花田。 |
| 管理入口 | 包内含管理页面构建资源及来源记录；管理操作仍需后端认证和授权。 |

## 常用设置

后台主题配置按 **外观与基础连接、首页与地图、总览指标、管理员工具、卡片列表、详情卡片、监控图表、自定义背景、花田文案、玻璃面板、地区连线** 分组。

- **数据连接**：默认 HTTP 轮询，更新间隔配置默认值为 3；启用 WebSocket 前确保反向代理支持升级连接。
- **模式切换**：`beijing` 模式在北京时间 07:00–18:59 使用明亮模式，其余时段使用夜里模式。
- **背景**：启用自定义模式背景后，选择图片或视频，并填写明亮/夜里背景地址。配置说明支持 HTTPS、站内 `/` 路径，以及 `local:文件名`。
- **服务器侧本地素材**：主题配置说明要求将文件放入 Komari 的 `data/theme/user-assets/`，再填写 `local:文件名`。实际挂载路径及支持情况需结合自己的 Komari 部署确认，这不是浏览器本地上传功能。
- **场景试听**：默认关闭，需要自行配置音频映射和来源；包内并未附带对应音频。
- **小屏与动效**：可选择更紧凑布局、关闭地区连线或减弱过渡动画；不保证未经实测的设备性能。

## 隐私与使用边界

- **不要在主题配置中填写真实密码、API Key 或 Token。** `exportSecondaryPassword` 的包内说明明确指出它只是客户端导出前确认，配置会通过公开 API 返回，不是安全密码。
- 隐藏后台入口或未登录时隐藏价格只是前端展示选项，不能替代后端权限控制。
- 外部图片、视频、音频链接会触发浏览器访问对应服务。构建代码中也包含 Iconify 及备用图标服务地址，因此不宣称完全无外部请求。
- 本次未连接实际 Komari 实例，也未完成真实浏览器交互、布局、后台操作和设备性能验收。
- 地图连线属于视觉示意，不是实测网络路径。
